# Leonida Nights — GTA 6 Cover Studio

Turn your photos into GTA 6-style multi-panel poster cover art, exported as PNG. A static offline web app — no network, no uploads.

## What it does

Pick a photo (yours or one of the three samples), choose one of 6 poster layouts and 6 sunset/neon colour grades, edit the stacked-white block title, script subtitle, tagline strip, billing block, seal, callouts, star-burst and ribbon — then export an exact-size PNG in 1080×1080, 1080×1350 or 1920×1080 with one click.

## Try it

```sh
node serve.ts
# open http://localhost:8080
```

Click any panel to select it, drag to move its photo, scroll to zoom. "Fill all panels with one photo" fills every panel with the selected photo.
